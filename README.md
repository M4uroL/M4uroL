## 👋 About

I build backend-focused, full-stack web applications with **Java / Spring Boot** and **Python / Flask**, and I'm currently deepening my skills in **microservices** and **cloud-native architecture**.

Beyond code, I'm the **founder and leader of [Kambas do Java](#-community)**, the Luanda Java User Group, and I work as a teacher. I care about solid engineering, clear communication, and growing the developer ecosystem in Angola and the Portuguese-speaking world.

**Goal:** to become one of Angola's leading developers, with international recognition, while putting Africa and the Lusophone community on the global Java map.

- Meetups, workshops and learning initiatives for developers at every level
- Outreach to the international Java community and speakers
- Beginner-friendly programs, including a computing course for new users
